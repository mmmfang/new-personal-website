# maefang.com Astro redesign brief

Build a safe, separate redesign of Mae F.'s portfolio without changing the live GitHub Pages site, production domain, DNS, or deployment settings.

Use Astro, Tailwind CSS, and MDX. Keep homepage copy in `src/data/siteContent.ts`, writing in `src/content/writing/`, and UI in reusable components. The visual direction is an elegant watercolor-inspired portfolio: warm cream, pink, lavender, sage, dark navy, rounded cards, paper texture, watercolor gradients, and wood-frame details.

Homepage: navigation; hero; core strengths; Sew What's Next flagship; One-Tap Transit; professional focus; AI Search Lab / Writing; AMA Generative AI for Marketing credential; about; and contact.

Safety: keep `mmmfang/mmmfang.github.io` untouched; do not add the production CNAME, deploy, commit, push, change DNS, or modify GitHub without explicit approval.
