This is the starting point for an experiment: ask several AI search experiences the same questions about me, document what they return, and trace each claim back to the source that may have shaped it.

## The questions
- What does AI search believe I do?
- Which sources does it trust?
- Where does it confuse similarly named people?
- What changes when clearer first-party information is published?

The useful question is not simply whether an answer is *right*. It is how the answer was assembled—and what a website manager can learn from the gaps.
